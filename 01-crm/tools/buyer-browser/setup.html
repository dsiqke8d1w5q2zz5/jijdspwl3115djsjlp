房仲管家・物件搜尋助手

這是供桌機 Chrome 使用的輔助工具。安裝後，「立即搜尋物件」會重新開啟原站搜尋；自動配對仍可同時開啟。不需要 AI Token 或付費 API。

一次性安裝

  1. 下載搜尋助手 ZIP，解壓縮到固定資料夾。
  2. 在 Chrome 網址列輸入 chrome://extensions。
  3. 開啟「開發人員模式」，按「載入未封裝項目」，選擇解壓後含有 manifest.json 的資料夾。
  4. 重新整理房仲管家，開啟「更多 → 買方需求配對」，確認顯示「搜尋助手已連接」。

這個自製助手尚未上架 Chrome 線上應用程式商店。請確認下列權限後再安裝。

需要的權限與資料用途

可開啟並讀取永慶、信義、591、樂屋、樂居的公開搜尋頁，以及和指定的房仲管家頁面互通。搜尋時會暫開背景分頁，完成後關閉；遇到驗證或登入限制會停止該站。

選取的買方需求及結果只保存在這個 Chrome 的擴充功能儲存空間。搜尋網址帶入縣市與行政區，買方姓名、電話不傳給房產網站；不讀取密碼、Cookie，也不要求其他網站的讀取權限。

搜尋範圍與執行條件

手動：每次按「立即搜尋物件」，針對目前買方重新搜尋五站首批資料。永慶、信義、樂屋、樂居為所選行政區第一頁，591 為所選縣市第一頁；不是全站完整清單。每次最多 40 個搜尋頁，超過時會提示縮小區域。

自動：勾選的買方每天本機時間上午 8:25 搜尋，需 Chrome 開啟且連網。關閉瀏覽器期間不能搜尋；重新開啟後由瀏覽器排程補觸發。網站更改頁面、要求登入或驗證仍可能失敗，結果會標示來源狀態。

手機或未安裝助手的裝置仍可使用雲端公開資料配對。信義、591 每天台灣時間 8:07 由雲端更新；永慶由已設定的 Windows 電腦於 8:17 補抓。

目前驗證狀態

已用一般瀏覽器讀取樂屋與樂居實際搜尋結果，並以保存的卡片樣本測試欄位解析。擴充功能仍需要在你安裝後，完成授權、實際開頁搜尋、回傳房仲管家的整段流程驗證；不能把樣本測試當成已全面啟用。
