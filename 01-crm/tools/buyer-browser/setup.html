房仲管家・物件搜尋助手

這是供桌機 Chrome 使用的輔助工具。安裝後，「立即搜尋物件」會重新開啟原站搜尋；自動配對仍可同時開啟。不需要 AI Token 或付費 API。版本 1.2.1：搜尋分批連續接續、頁面可讀即解析，符合物件邊找邊顯示。

使用 EXE 安裝或更新至 1.2.1

下載 Windows 安裝／更新工具 EXE

  1. 開啟更新工具 1.0.2。沒有原檔案請按「選擇資料夾安裝」，使用檔案總管式視窗選擇空白資料夾（可雙擊逐層進入、在網址列貼上路徑，或建立新資料夾）；已有助手則按「更換／更新助手資料夾」。工具會下載、核對及解壓縮，無須原檔案或自行處理 ZIP。
  2. 首次安裝：按工具內「開啟 Chrome 擴充功能」，開啟「開發人員模式」，按「載入未封裝項目」，選擇工具顯示的助手資料夾。
  3. 從 1.1 舊版升級：請在 Chrome 擴充功能頁最後一次按助手的重新載入。1.2 版起，更新工具會開啟房仲管家並請已連接的助手重新載入；搜尋進行中會延後重新載入。
  4. 以後更新，執行同一個 EXE 即可，工具會記住原資料夾。請使用安裝助手的同一個 Chrome 設定檔。
  5. 重新整理房仲管家，開啟「買方需求配對」，確認顯示「搜尋助手已連接」。

EXE 尚未取得程式碼簽章，Windows 可能顯示未知發行者。請只使用本頁下載檔；工具不要求管理員權限、不變更防毒或 Chrome 安全設定。

這個自製助手尚未上架 Chrome 線上應用程式商店。請確認下列權限後再安裝。

需要的權限與資料用途

可開啟並讀取永慶、信義、591的公開搜尋頁，以及和指定的房仲管家頁面互通。搜尋時會暫開背景分頁，完成後關閉；遇到驗證或登入限制會停止該站。

選取的買方需求與助手搜尋歷史保存在此 Chrome。房仲管家收到後，完整結果保存在網頁的本機資料庫；收藏摘要與追蹤備註隨客戶資料保存／同步。搜尋網址帶入縣市與行政區，買方姓名、電話不傳給房產網站；不讀取密碼、Cookie，也不要求其他網站的讀取權限。

搜尋範圍與執行條件

手動：在買方詳細頁按「立即搜尋」，依這位買方的行政區逐頁讀取三站搜尋結果，並套用需求篩選。搜尋分批接續並顯示頁數，只有核對末頁才標示該區完成；原站限制、驗證、重複頁與讀取失敗會標示未完成。不是整個網站的完整資料庫。

自動：在買方詳細頁勾選「自動配對」的買方每天本機時間上午 8:25 搜尋，需 Chrome 開啟且連網。關閉瀏覽器期間不能搜尋；重新開啟後由瀏覽器排程補觸發。網站更改頁面、要求登入或驗證仍可能失敗，結果會標示來源狀態。

手機或未安裝助手的裝置仍可使用雲端公開資料配對。信義、591 每天台灣時間 8:07 由雲端更新；永慶由已設定的 Windows 電腦於 8:17 補抓。
